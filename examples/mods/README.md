# 예제 모드

만드는 법은 **[`MODDING.md`](../../MODDING.md)**가 적는다(공개 저장소 기준 경로다). 여기 있는 것은 그대로 복사해서 고치는 것이
가장 빠른 시작이 되도록 둔 표본이다.

## 쓰는 법

`Kkamnyang.exe` 옆에 `mods/` 폴더를 만들고 이 폴더를 통째로 복사한다(웹판은 모드를 읽지 않는다):

```
Kkamnyang.exe
res/
mods/
  rooftop-dash/
```

설정 → 일반 → **모드 관리**에서 켠다. 기존 판을 덮는 모드라 ⚠가 붙는다.

## rooftop-dash — 맵 모드(코드 없음)

서장 **0-1**을 사람 몸으로 달리는 짧은 연습판(96×20칸)으로 바꾼다. 스테이지 순서는 `data/chapters.json`이 정하고 모드가 고칠 수 없으므로,
새 판은 **기존 판의 `id`로** 넣는다 — 여기서는 늘 열려 있는 `0-1`.

| 건드리는 것 | 파일 | 확인하는 법 |
|---|---|---|
| 맵 | `maps/0-1.json` | 허브의 서장 첫 판이 「지붕 질주」가 되고, 고양이가 아니라 사람 몸으로 시작한다 |
| 글 | `locales/ko/stages.json` · `locales/en/stages.json` | 판 이름과 말풍선 셋(그래플 안내는 터치용 `_touch` 판도 있다) |

맵이 보여 주는 것: 그래플로만 건너는 틈(등롱 고리 둘) → 체크포인트 → 무너지는 기와 다리(아래는 가시) → 들보 계단으로 오르는
높은 지붕(포졸봇) → 골. 원래 0-1의 도입·맺음 대사(`intro`·`outro`)는 이 맵에 적지 않았으니 나오지 않는다.

이 맵은 게임이 제 판들을 검사하는 콘텐츠 검증기에 원래 0-1 대신 넣어 통과하는 것을 확인했다 — 골까지 닿고, 모든 엽전·적에 닿을 수 있다.
`layout`의 줄은 모두 같은 길이(여기서는 96)여야 한다.
