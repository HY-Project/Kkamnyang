<h1 align="center">깜냥</h1>
<p align="center">
  <b>Kkamnyang</b><br>
  <sub>HY Project presents · #K-01</sub>
</p>

---

조선이 끝나지 않은 평행우주의 서울, 개국 646년의 네온 메가시티 **신한양**. 하늘의 공중 궁궐에서 떨어진 파편을 삼킨
까만 길고양이가 사람처럼 서서 지붕 위를 달리는 **도트 횡스크롤 플랫포머**입니다.

**깜냥**은 두 뜻입니다 — *깜+냥*, 까만 고양이. 그리고 사전의 *깜냥*, 스스로 일을 헤아릴 만한 능력. 까만 고양이가
제 깜냥을 찾아 가는 이야기입니다.

---

## 플레이

| | |
|---|---|
| **Windows x64** | [Releases](https://github.com/HY-Project/Kkamnyang/releases/latest)의 `Kkamnyang_<버전>_windows_x64.zip` — 풀어서 `Kkamnyang.exe`를 실행 |
| **HY 런처용** | 같은 릴리스의 `Kkamnyang_<버전>_windows_x64.hyp` |

- **지금은 Windows x64 한 벌만 나갑니다.** macOS · Linux · arm64는 아직 없습니다.
- 푼 폴더 안에서 처음 실행하면 그 옆에 `save/` · `logs/` · `mods/`가 생깁니다. 새 판으로 옮길 때는 새 압축본을 풀고
  `save/`(모드를 쓴다면 `mods/`도)를 옮겨 주면 됩니다.
- **게임은 인터넷이 필요 없습니다.** 바깥에 아무것도 묻지 않고 끝까지 진행됩니다.

### 사양

| | |
|---|---|
| 운영체제 | **Windows 10 / 11** (x64) |
| 그래픽 | WebGPU 또는 WebGL2 |
| 그 외 | Microsoft Edge WebView2 (Windows 11에는 기본으로 들어 있습니다) |

## 무엇을 하는 게임인가

**달리고, 매달리고, 쏩니다.** 속도가 붙는 관성 이동에 그래플링 후크 · 구르기 · 웅크려 미끄러지기 · 벽 차기를 얹고, 손에는
네온 레이저를 듭니다. 스테이지는 짧고 빠른 직선 코스에 그래플로만 닿는 숨은 갈래가 붙어 있습니다.

| | |
|---|---|
| 무대 | 서장부터 종장까지 **일곱 장** — 운종가 뒷골목 · 지붕과 전깃줄 · 육의전 타워 · 마포 조병창 · 한강 양화진 · 남산 봉수망 · 공중 궁궐 근정 아크 |
| 동료 | **다섯** — 깜냥 · 볕뉘 · 희나리 · 해미 · 엄장. 셋을 골라 **태그 교대**로 갈아 끼웁니다 |
| 속성 | **오방색** — 흑 · 적 · 백 · 청 · 황. 적의 방패는 상극하는 색으로 쏴야 금방 깨집니다 |
| 성장 | 품계(전역 레벨) · 캐릭터 레벨 · 스킬 Q · E · R. 스킬은 판마다 한 번 놓인 **비급 쪽**으로 올립니다 |
| 저장 | **자동 저장 한 칸** — 스테이지를 끝낼 때와 스킬 · 편성이 바뀔 때 저절로 남습니다 |

**동료가 모두 쓰러지면 그 판은 실패입니다.** 떨어지거나 차오르는 불에 닿으면 체크포인트에서 다시 서지만, 마지막 동료가
쓰러지면 보상도 기록도 남지 않습니다.

## 모드

**모드를 지원합니다.** 게임 폴더의 `mods/`에 폴더나 `.zip`을 넣으면 읽습니다. 그림 · 소리 · 캐릭터 · 적 · 보스 · 아이템 ·
물리 조율값을 덮을 수 있고, 게임 안 **설정 → 일반 → 모드 관리**에서 순서와 켜고 끄기를 다룹니다. 모드 때문에 게임이
안 켜지면 저절로 안전 모드로 뜹니다.

만드는 법은 **[MODDING.md](MODDING.md)** 에 있습니다.
